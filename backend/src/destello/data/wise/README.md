# WISE relative spectral response

`RSR-W1.txt` and `RSR-W2.txt` are unmodified copies of the official WISE relative spectral
response per photon (Wright et al. 2010, AJ 140, 1868), downloaded on 2026-11-14 from
`https://irsa.ipac.caltech.edu/data/WISE/docs/release/All-Sky/expsup/figures/RSR-W1.txt` and
`RSR-W2.txt`. Columns: wavelength (um), relative response, uncertainty (parts per thousand).
